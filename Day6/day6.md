# 📄 Day 6 — ATS Resume Optimization with Claude

## 🎯 Objective

The objective of Day 6 was to use **Claude AI** to analyze and optimize my resume for **Applicant Tracking System (ATS) compatibility**.

I compared my original resume with the optimized version, identified formatting and content issues, and used Claude's recommendations to create a cleaner, keyword-optimized, **one-page ATS-friendly resume**.

# 🔍 Part 2 — Issues Found in the Original Resume

Claude identified several areas that could negatively affect ATS parsing and recruiter readability.

### 1. Corrupted Formatting

The original resume contained broken markdown artifacts such as:

```text
**Bachelor of Technology (B.Tech) ****&**** Engineering**
```

These formatting artifacts could cause text to be extracted incorrectly by an ATS.

The optimized version converted this into clean, plain text.

---

### 2. Non-Standard Section Headings

The original resume used **"Internships"** as a section heading.

The optimized resume standardized headings using commonly recognized ATS labels:

* Professional Summary
* Education
* Experience
* Projects
* Skills
* Certifications

This makes it easier for ATS systems to correctly classify resume information.

---

### 3. Missing Professional Summary

The original resume did not contain a professional summary.

A keyword-rich **Professional Summary** was added near the top of the resume, highlighting relevant areas such as:

* Artificial Intelligence
* Machine Learning
* Computer Vision
* Natural Language Processing
* Python

This helps communicate my technical profile quickly to recruiters and ATS systems.

---

### 4. Repetitive Project Descriptions

Some project descriptions repeated the same information multiple times.

For example, the concept of **2-class classification** was repeated in different parts of one project.

The optimized version consolidated repetitive information into stronger and more concise bullet points.

---

### 5. Formatting and Layout

The original formatting contained elements that could potentially interfere with reliable ATS text extraction.

The optimized resume uses:

* Single-column layout
* Plain text
* Standard section headings
* No tables
* No unnecessary special symbols
* No leftover markdown formatting
* Consistent spacing

---

### 6. Skills Organization

The original skills section was presented more like a flat list.

The optimized version grouped skills into clear categories:

```text
Languages
AI-ML & CV
Core CS
Tools
```

This improves both keyword matching and recruiter readability.

# 🧠 Part 8 — Key Learnings

### 1. ATS-Friendly Formatting Is Important

A resume should be designed not only for human readers but also for automated systems that extract and categorize resume information.

### 2. Standard Headings Improve Parsing

Using familiar headings such as **Experience, Education, Projects, Skills, and Certifications** makes the resume structure easier for ATS systems to understand.

### 3. Keywords Should Be Relevant

Adding relevant technical keywords can improve the discoverability of skills, but keywords should accurately represent my actual knowledge and experience.

### 4. Avoid Unnecessary Repetition

Repeating the same information does not necessarily make a resume stronger. Concise and focused bullet points communicate achievements more effectively.

### 5. Quantifiable Results Matter

Where genuine data is available, numbers such as accuracy, dataset size, team size, or measurable outcomes can make achievements clearer and more impactful.

### 6. Simple Formatting Works Better for ATS

A clean, single-column layout with standard text formatting can reduce the risk of information being incorrectly extracted by ATS software.

### 7. AI Can Be Used as a Resume Reviewer

Claude can help identify weaknesses that may be difficult to notice during a normal resume review, especially around formatting, keywords, structure, and repetition.
