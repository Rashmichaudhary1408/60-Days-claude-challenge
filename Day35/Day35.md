# Day 35: Build Prompt Puzzle
### Master AI Prompting Through Play

## 1. Topic
Build **Prompt Puzzle**, an interactive single-file HTML game that teaches AI prompting through drag-and-drop challenges, live scoring and a performance report.

## 2. Goal
Show how a detailed prompt, including an onboarding interview, can make Claude generate a complete, playable learning app that works offline.

## 4. What I Built

- **Screens and Steps Poster**: a visual guide to all six screens and the nine steps.

## 6. The Three Challenge Types
1. **Build the Prompt**: drag blocks into Role, Task, Context, Format and Constraint slots (some blocks are distractors).
2. **Clean the Prompt**: remove the noisy lines and keep what the AI needs.
3. **Choose the Best Prompt**: pick the best of a weak, an optimized and an over-engineered prompt.

## 7. Scenarios (6)
1. Sneaker launch email
2. Coffee shop caption
3. Late delivery reply
4. Water bottle description
5. Fitness app headline
6. Product launch tweet

Each scenario includes: desired output, correct blocks, distractors, weak prompt, optimized prompt, over-engineered prompt, weak AI output, optimized AI output and a prompt principle.

## 8. Scoring
- Accuracy
- Time
- Moves
- Wrong placements
- Hints used (-6 each)
- Optimization bonus (+8 for no mistakes and no hints)

## 9. Performance Report
- Prompt score
- Rating: Rookie, Apprentice, Crafter or Architect
- Rank: Bronze, Silver or Gold League
- Prompt DNA (Role, Task, Context, Format, Constraint)
- Personalized feedback and next milestone
- Final optimized prompt with copy button

## 12. Key Prompt Principles Practiced
- Give the AI a clear **role**
- State one specific **task**
- Add **context** such as audience and goal
- Define the **format** and length
- Set **constraints**, but don't over-engineer

## 13. Lessons Learned
- An interview-first prompt makes the app fit the user's choices.
- Vanilla JavaScript is more reliable than React via CDN for offline files.
- Learning by playing is more memorable than reading about prompts.
- Always test in a real browser before calling it finished.
