# Day 7 — My Claude Usage Strategy

## 🎯 Objective

The goal of Day 7 was to understand how to use Claude more effectively by selecting the right model and effort level for different types of tasks.

I analyzed my personal workflow, daily activities, and common AI use cases, then created a personalized Claude Usage Strategy.

---

## 👩‍💻 My Profile

* **Current Situation:** Student
* **Primary Activities:** Coding, AI/ML learning, exam preparation, research, resume building, career preparation, content creation, and project development
* **Claude Usage:** Daily / Heavy User
* **Most Needed Outputs:** Learning support, coding help, research assistance, career support, and creative work

---

## 🤖 Recommended Primary Model

### Claude Sonnet

Claude Sonnet is the best primary model for my everyday workflow because I regularly switch between coding, learning, writing, debugging, project work, and career preparation.

It provides a strong balance between:

* Reasoning quality
* Coding ability
* Learning support
* Writing quality
* Speed
* Practical everyday usage

---

## 🔍 When to Use Each Claude Model

| Model      | Best For                       | My Use Cases                                                                       |
| ---------- | ------------------------------ | ---------------------------------------------------------------------------------- |
| **Haiku**  | Fast and simple tasks          | Quick definitions, syntax checks, short explanations, simple rewrites              |
| **Sonnet** | Balanced reasoning and quality | Coding, debugging, learning, project help, resume improvement, exam preparation    |

## ⚙️ Recommended Effort Level

### Low

Use for:

* Simple questions
* Quick definitions
* Short rewrites
* Basic syntax
* Straightforward calculations

### Standard

Use for:

* Regular coding
* Learning concepts
* Debugging
* Resume improvements
* General research
* Daily productivity

**This should be my default effort level for most tasks.**

### High

Use for:

* Difficult programming problems
* Complex project planning
* Detailed technical explanations
* Advanced AI/ML concepts
* Multi-step reasoning

### Max

Use selectively for:

* Very difficult algorithmic problems
* Deep research
* Complex system design
* Important project decisions
* Problems requiring maximum reasoning depth

## 🔄 Daily Claude Workflow

### Step 1 — Define the Task

Clearly describe what I want Claude to accomplish.

### Step 2 — Add Context

Provide relevant information such as:

* Current skill level
* Project requirements
* Code
* Constraints
* Expected output format

### Step 3 — Choose the Right Model

* **Haiku** → Quick/simple tasks
* **Sonnet** → Everyday work
* **Opus** → Complex/deep work

### Step 4 — Select Effort

* **Low** → Simple task
* **Standard** → Normal task
* **High** → Complex task
* **Max** → Critical/deep reasoning

### Step 5 — Review the Output

Check accuracy, assumptions, code, and whether the response satisfies the requirement.

### Step 6 — Iterate

Give Claude targeted feedback instead of restarting the entire task.

### Step 7 — Save Useful Results

Store important prompts, workflows, screenshots, and learnings for future reference.

## 💡 Key Learnings

1. The most powerful model is not always necessary for every task.
2. Model selection should depend on task complexity.
3. Effort settings can help balance speed and reasoning depth.
4. Sonnet is a practical default for my daily technical and learning workflow.
5. Haiku is useful for quick, low-complexity tasks.
6. Opus should be reserved for tasks that genuinely require deeper reasoning.
7. Providing Claude with clear context improves the usefulness of the output.
8. Reviewing and iterating on AI-generated results is an important part of an effective AI workflow.

---

## 🚫 Biggest Mistakes to Avoid

* Using the most powerful model for every simple task
* Increasing effort when the problem does not require deeper reasoning
* Giving Claude incomplete context
* Accepting generated code without testing it
* Using AI output without reviewing accuracy
* Writing extremely vague prompts
* Spending unnecessary usage on tasks that can be solved quickly

---

## 🏆 Final Recommendation

### If I could use only ONE model and ONE effort level:

**Claude Sonnet + Standard Effort**

This combination fits my daily workflow because I frequently work on coding, AI/ML learning, projects, exam preparation, resume building, research, and content creation.

For more difficult tasks, I can temporarily increase the effort level or switch to Opus instead of using maximum resources for everything.
