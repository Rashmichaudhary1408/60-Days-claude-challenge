# Day 11 — ATS Resume Optimizer

## Task
Used Claude to analyze my resume against a target job description, generate an ATS match score and gap analysis, and produce an ATS-optimized resume.

## Target Role
AI/ML Software Engineer

## ATS Match Score
68/100 (initial)

## Key Gaps Identified
- Missing keywords: SDLC, debugging, testing, REST API, Agile
- Missing skills: no coding-practice platform mentioned, no explicit backend/API project
- Resume was framed as ML specialist rather than Software Engineer

## What I Did
- Reframed Professional Summary and Skills section around Software Engineering language
- Integrated JD-relevant keywords naturally without inventing new experience
- Restructured for a clean one-page ATS-friendly format

## Learnings
- ATS scoring depends heavily on how existing experience is *framed*, not just what's listed
- Keyword alignment must stay factual — optimization is about rephrasing, not fabricating
- A one-page format required deliberate spacing/content trade-offs without losing key achievements
